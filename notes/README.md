# 学习笔记目录

## 命名规范

```
notes/YYYY-MM-DD-简短主题.md
```

示例：
- `notes/2026-07-01-flutter-cross-platform-architecture.md`
- `notes/2026-07-03-dart-ffi-llama-cpp.md`
- `notes/2026-07-05-go-gin-middleware.md`

## 内容范围

- 技术讨论的总结和要点
- 架构决策的记录
- 踩坑和经验教训
- 对某一主题的深入学习笔记

## 规范

- 一篇笔记聚焦一个主题，不超过 3 个紧密关联的子主题
- 开头用 2-3 句话说明这篇笔记的场景（为什么产生了这个讨论）
- 文末标注日期和参与方
- 不替代 PRD、plan、代码注释——笔记是学习过程的记录，不是交付物
- 笔记不需要像文档一样完美，允许口语化表达
