# 学习笔记目录

## 目录结构

```
notes/
  YYYY-MM-DD/
    SUMMARY.md              ← 当天工作总结（完成事项、关键决策、Bug 修复、Git 提交等）
    xxx-topic.md            ← 深度笔记（随时记录，不限数量）
    yyy-idea.md             ← 想法/提问（任何时间冒出来的都可以丢进来）
```

## 使用方式

1. **白天随时记**：想到什么直接在当天目录下新建 `.md` 文件，不要求命名规范，内容随意
2. **晚上做总结**：打开当天的 `SUMMARY.md`，把当天的工作完成情况写进去，也可以对照白天的碎片笔记做汇总

## 命名建议

- `SUMMARY.md` — 固定名称，当天的工作总结
- 其他文件 — 简短描述主题即可，如 `prompt-tuning-log.md`、`flutter-core-concepts.md`

## 内容范围

- SUMMARY.md：每日开发总结（完成事项、技术选型、Bug 修复、关键决策、Git 提交记录）
- 深度笔记：技术讨论、架构决策、踩坑经验、深入学习
- 想法/提问：当天冒出来的任何想法、后续想探索的方向

## 规范

- SUMMARY.md 保持结构化，方便快速回顾
- 其他笔记可以口语化，不要求完美
- 不替代 PRD、plan、代码注释——笔记是学习过程的记录，不是交付物
