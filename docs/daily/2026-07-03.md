# 2026-07-03 开发总结

## 今日主题：Day 2 — 端侧推理接入（llama.cpp + Qwen3.5-2B）

---

## 一、技术选型

评估了 3 个 Flutter llama.cpp 封装包：

| 包 | 许可证 | 支持平台 | 结论 |
|---|---|---|---|
| `flutter_llama` | NONC（限制商用） | 三端 | ❌ 许可证不可用 |
| `dart_llama` | MIT | 仅 macOS/Linux | ❌ 不支持移动端 |
| `llama_cpp_dart` | MIT | iOS/Android/macOS | ✅ 内置 Isolate、ChatML、预编译二进制 |

**选择**：`llama_cpp_dart` v0.9.0-dev.9，从 GitHub Releases 获取预编译二进制。

---

## 二、集成内容

### 2.1 三端预编译二进制

- `llama.xcframework`（iOS + macOS，17.7MB）→ `ios/Runner/`
- `llama-cpp-dart.aar`（Android arm64-v8a，2.3MB）→ `android/app/libs/`
- `macos-libllama.zip`（macOS dylibs）→ `macos/Runner/libs/`

### 2.2 平台集成配置

- **Android**：AAR 放入 `android/app/libs/`，`build.gradle.kts` 添加 `implementation(files())`
- **iOS**：xcframework 放入 `ios/Runner/`
- **macOS**：
  - 添加 "Copy LLM Dylibs" Build Phase → dylib 自动复制到 `Contents/Frameworks/`
  - `temporary-exception` entitlement 白名单模型文件
  - Sandbox 保持 `true`

### 2.3 核心代码

| 文件 | 作用 |
|------|------|
| `lib/core/llama_service.dart` | 推理服务单例：模型加载、流式 token、追问维度轮换、去重检测 |
| `lib/core/constants.dart` | 模型路径、上下文配置常量 |
| `lib/features/chat/providers/chat_provider.dart` | 异步 sendMessage + 流式 token 拼接 + Mock 回退 |
| `lib/features/chat/chat_page.dart` | 自动加载模型、滚动到底部、加载提示条 |

### 2.4 模型

- **初始**：Qwen2.5-1.5B-Instruct Q4_K_M（~1.06GB）
- **最终**：Qwen3.5-2B-Instruct Q4_K_M（~1.2GB）— 指令遵循能力更强
- 从 hf-mirror.com 下载至 `assets/models/`

## 四、Prompt 优化历程（v1→v5）

针对 Qwen2.5-1.5B 小模型进行了 5 轮追问质量迭代，并最终升级为 Qwen3.5-2B：

| 版本 | 策略 | 结果 |
|------|------|------|
| v1 | 简单维度标签 `追问维度：【原因】\n用户输入` | 基本可用，多轮后重复 |
| v2 | Dart 端去重 + 重试（公共子串 >60% 切换维度） | 重复减少，不稳定 |
| v3 | 复杂结构 prompt（对话结构、绝对禁止列表） | ❌ 规则太多，更差 |
| v4 | 用户消息嵌入开场白（三层标签） | ❌ 模型困惑，更差 |
| v5 | `addAssistant` 注入 + few-shot prompt | ✅ 当前最佳 |

### 核心经验

1. **小模型提示词越少越好** — 每条规则都是干扰源
2. **few-shot > 规则描述** — 模型"照猫画虎"比"读懂规则"强
3. **复杂逻辑放代码层** — 去重、维度轮换在 Dart 端解决
4. **消息格式遵循 ChatML 规范** — `addAssistant` 而非文本拼接

详细记录见 `docs/notes/2026-07-03-llm-prompt-tuning-log.md`

## 五、Bug 修复记录

| 问题 | 根因 | 修复 |
|------|------|------|
| 多行字符串编译错误 | `'''` 结尾缺 `;` | 添加分号 |
| Sandbox 文件读取被拒 | `Directory.current` 指向 Container | 从 `Platform.resolvedExecutable` 解析 |
| 模型加载成功但用 Mock | ChatPage 未调用 `loadModel` | StatefulWidget + initState |
| `seedContext` 永不触发 | AI 占位消息先加入 length≠2 | 改用 `_round == 1` 判断 |
| 消息不自动滚动 | 无 ScrollController | addPostFrameCallback + animateTo |
